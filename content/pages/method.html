Method

Africa on the Ground puts two kinds of knowledge side by side on each place card and never mixes them.

The record

Every statement in the record layer carries a numbered citation. The sources are listed at the bottom of the card, each labelled with its kind: institutional (for example a UNESCO page), press, academic, primary, or encyclopedia. A source marked "to verify" is a starting point, meant to be confirmed or replaced by a stronger one. Each card also lists what is not yet sourced.

Local voices

A local note is one person's experience, written in their own words and shown as theirs. Notes are collected in person or by direct message from people the project can reach, and published only with the author's agreement. Authors choose whether to give a name and how to describe their connection to the place. The project does not verify either. Notes are not edited, except for typing slips agreed with the author, and a translation is marked as one.

When a note disagrees with the record

Neither layer overwrites the other. If a note says the record reads wrong, the project looks for a source that settles the point. The record changes only when one is found, and the change is cited like everything else.

Photographs

Photographs come from Wikimedia Commons and carry an open licence. Each card gives the photographer, the licence and a link to the original file. A photograph shows a place on one day, so it is an illustration and not a statement about how the place looks now.

What this site collects

Nothing. There are no forms, no cookies, no analytics and no files loaded from other sites. The site is hosted on GitHub Pages, whose servers may keep their own logs. The project does not control or see them.

Removing a note

An author can ask at any time for their note to be removed.
