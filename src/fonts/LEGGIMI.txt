FONT LOCALI (facoltativi)

Il sito funziona con i font di sistema. Per usare i font scelti per il progetto senza che i
visitatori chiamino server esterni (per esempio Google), scarica i file e salvali qui con
questi nomi esatti, in formato woff2:

  bricolage-grotesque-variable.woff2      Bricolage Grotesque, variabile, pesi 300-800
  source-serif-4-variable.woff2           Source Serif 4, variabile, pesi 400-700
  source-serif-4-italic-variable.woff2    Source Serif 4 corsivo, variabile
  ibm-plex-mono-400.woff2                 IBM Plex Mono Regular
  ibm-plex-mono-500.woff2                 IBM Plex Mono Medium

Il build li incorpora da solo e scrive le regole @font-face. Se un file manca, quel font
viene semplicemente ignorato.

Prima di pubblicarli controlla la licenza di ciascun font (di solito sono licenze aperte che
permettono di servirli dal proprio sito, ma va verificato file per file) e conserva qui
accanto il testo della licenza che accompagna il download. Scarica i file da una fonte
ufficiale e controlla che il subset includa le lettere accentate che ti servono.
